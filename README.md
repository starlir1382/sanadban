# سامانه جامع سَنَدبان (SanadBan / DeedFlow)
## سامانه هوشمند مدیریت اسناد، ارزیابی و گردش پرونده‌های طرح نهضت ملی مسکن

سیستم سازمانی و اداری طراحی‌شده برای مدیریت گردش کار ۲۲ مرحله‌ای، استعلامات ثبتی و صدور معرفی‌نامه محضر میان کارگزاری‌های مسکن و اداره کل راه و شهرسازی.

---

### ویژگی‌های کلیدی سامانه
- **گردش کار ۲۲ مرحله‌ای (22-Stage Workflow):** پوشش کامل کلیه مراحل از ورود اطلاعات متقاضی و همسر تا استعلام فرم ج، ارزیابی، تسویه با پیمانکار، صدور نامه محضر و بایگانی قطعی.
- **گالری و لایت‌باکس اسکن مدارک (Document Scans & Viewer):** مشاهده اسناد با قابلیت زوم چندبرابری، چرخش ۹۰ درجه، بررسی اصالت با هش امنیتی SHA-256 و شبیه‌ساز ارتباط با اسکنرهای سخت‌افزاری (WIA/TWAIN).
- **قفل فرامرحله‌ای و امنیت اسناد (Immutable Attachments):** اسناد بارگذاری‌شده در مراحل قبلی توسط کاربران مراحل بعدی غیرقابل حذف است.
- **فرمول زنده محاسبه آورده متقاضی:** کسر خودکار وام صندوق و تسهیلات دهک از قیمت تمام‌شده پایه همراه با تبدیل بلادرنگ به حروف ریال و شبیه‌سازی ارسال پیامک.
- **تایپوگرافی و طراحی کامپوننت‌های RTL:** طراحی استاندارد با فونت وزیرمتن و رابط کاربری فارسی سازمانی.
- **موتور چاپ رسمی اداری:** قالب‌های استاندارد A4 جهت چاپ معرفی‌نامه دفتر اسناد رسمی (محضر) و شناسنامه بایگانی پرونده.

### ساختار پوشه‌های پروژه
```text
sanadban/
├── config/                  # پیکربندی اصلی جنگو (settings, urls, wsgi)
├── workflow/                # اپلیکیشن اصلی گردش کار و پرونده‌ها
│   ├── models.py            # مدل‌های HousingDossier, DossierAttachment, WorkflowSignatureLog
│   ├── views.py             # ویوهای داشبورد، جزئیات پرونده، ذخیره پیش‌نویس، امضا و اسکن
│   ├── urls.py              # مسیرهای مسیریابی سامانه
│   └── context_processors.py# ارائه‌دهنده تقویم شمسی پویا (تاریخ روز جاری)
├── templates/               # قالب‌های HTML جنگو و تمپلیت‌های چاپ
│   ├── base.html            # پوسته اصلی سامانه با هدر اداری
│   ├── dossier_detail.html  # میز کار اصلی مدیریت پرونده
│   ├── dossier_list.html    # داشبورد پایش و فیلتر پرونده‌ها
│   ├── notary_letter_print.html  # چاپ معرفی‌نامه محضر
│   ├── dossier_print_summary.html # چاپ شناسنامه بایگانی
│   └── components/          # کامپوننت‌های ماژولار (استپر ۲۴ مرحله، گالری اسکن، فرم‌ها و مودال‌ها)
├── static/
│   ├── css/sanadban.css     # سیستم استایل سازمانی RTL
│   └── js/sanadban.js       # موتور تعاملی Alpine.js
├── db.sqlite3               # پایگاه داده محلی همراه با پرونده‌های نمونه آزمایشی
├── manage.py
└── requirements.txt
```

### راهنمای راه‌اندازی و اجرا

#### ۱. نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

#### ۲. اعمال مایگریشن‌ها (در صورت نیاز)
```bash
python manage.py migrate
```

#### ۳. اجرای سرور توسعه
```bash
python manage.py runserver
```

سپس در مرورگر به آدرس‌های زیر مراجعه نمایید:
- **داشبورد پرونده‌ها:** [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
- **میز کار پرونده متقاضی:** [http://127.0.0.1:8000/dossier/100001/](http://127.0.0.1:8000/dossier/100001/)
- **پنل مدیریت جنگو:** [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/) (نام کاربری: `admin` / رمز عبور: `admin123456`)
